# 🌌 Antigravity Tic-Tac-Toe // Space Sci-Fi Zero-G Protocol

A futuristic, zero-gravity Antigravity & Space Sci-Fi Tic-Tac-Toe web game featuring 3D holographic visuals, interactive cosmic physics, glassmorphism, procedural Web Audio SFX, and Quantum Minimax AI.

---

## 🚀 Features

- **Cosmic Void & Parallax Physics**: Dynamic HTML5 canvas starfield with twinkling zero-g stars, nebular dust particles, and rotating digital orbit rings that respond to mouse parallax.
- **3D Weightless Floating Board**: Interactive 3D perspective 3×3 game board hovering in zero gravity with live gyroscopic tilt.
- **Glassmorphism Cyber Tiles**: 9 semi-transparent frosted cells with cut-corner cyber brackets, glowing neon cyan (`X`) and electric pink (`O`) holographic 3D symbols with lens flares.
- **Side HUD Gauges**: Real-time animated `GRAV-FLUX` and `QUANTUM-CORE` energy meters flanking the arena.
- **Dynamic Turn Panels**: Floating glassmorphism cards for `PLAYER X` and `PLAYER O` with animated radar sweep rings, SVG pilot avatars, telemetry dials, and active turn beacons.
- **Telemetry & Battery Progress**: 9-stage segmented sector energy meter tracking moves (1–9), nominal gravity stabilization readouts, and persisted holographic scoreboards.
- **Quantum AI Core**: Switchable game mode (`2P LOCAL` vs `VS AI CORE`) powered by an optimal Minimax algorithm with tactical simulated scanning delay.
- **Procedural Web Audio Engine**: Zero-dependency synthesized audio via Web Audio API (laser chirps, plasma pulses, victory chords, stalemate glitch frequencies, and power-down sweeps).

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with accessibility metadata
- **Styling**: Vanilla CSS3 (Custom 3D transforms, Glassmorphism, Neon Glow Filters, Cyber Animations)
- **Logic & Physics**: Pure JavaScript (Canvas 2D render loop, Minimax AI, Web Audio API, LocalStorage telemetry)

---

## 🎮 How to Play

1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser or run via a local server:
   ```bash
   # Python
   python -m http.server 8080

   # Or Node
   npx serve .
   ```
3. Pilot `X` (Neon Cyan) opens first. Take turns claiming sectors or toggle `MODE: VS AI CORE` to challenge the quantum computer.
4. Align 3 holographic symbols horizontally, vertically, or diagonally to trigger the orbital victory transmission and energy laser beam!
